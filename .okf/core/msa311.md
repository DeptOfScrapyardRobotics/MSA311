# Role

`MSA311` extends `GeneralPurposeIO\Circuits\Types\SensorIC`, implements `BootSequence` and `Waveforms\Contracts\Motion\MeasuresAcceleration`. Attributes are GeneralPurposeIO Circuits (`#[IntegratedCircuit('I2C')]`, `#[Pinout(...)]`) — not Fabricate Circuits.[^msa311]

# Identity / bus

| Item | Value |
|------|-------|
| I2C address | `MSA311I2CAddress::DEFAULT` = **0x62** |
| PARTID / WHO_AM_I | register **0x01**, expect **0x13** |
| XYZ data | `0x02`…`0x07` (X/Y/Z L/H, 14-bit left-aligned in 16-bit LE) |

Boot confirms PARTID, enables all axes, then applies Adafruit defaults: NORMAL power, 500 Hz ODR, 250 Hz bandwidth, ±4 g, 14-bit.[^internal][^adafruit-cp]

# Acceleration (g)

`x()` / `y()` / `z()` return **g**. Raw path: signed LE int16 → `>> 2` → divide by range `lsbPerG()` (±2g→4096, ±4g→2048, ±8g→1024, ±16g→512). `MSA311Range::mgPerLsb()` exposes the matching mg/LSB.[^api]

# Factories

```php
MSA311::i2c($device, adapter: null, slave: 0x62, boot_now: true);
MSA311::fromI2CBus($i2cSlave, boot_now: true);
```

Transport: `MSA311CarrierTransport` + `MSA311IO` (register-prefixed I2C write/writeRead).[^transport]
